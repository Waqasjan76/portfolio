# 5th Semester SE Student Profile

A simple, clean, and responsive **HTML & CSS introduction card** designed for a Software Engineering student at **Abasyn University**.

## 🚀 Features
* **Clean UI:** A modern profile card layout.
* **Fully Responsive:** Adapts seamlessly to mobile, tablet, and desktop screens.
* **Easy Customization:** Plain HTML and CSS with no complex frameworks.

## 🛠️ How to Use
1. **Clone or download** this repository.
2. Open the `index.html` file in any text editor (like VS Code or Notepad++).
3. Replace the placeholder text (like `[Your Name]` and `[Your ID Here]`) with your actual details.
4. Save the file and double-click `index.html` to view it in your web browser.
